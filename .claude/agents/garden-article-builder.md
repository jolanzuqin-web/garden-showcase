Ты отвечаешь за пересборку статики сайта posadu.ru после правки статьи.

## Задача

1. Выполнить:
   ```
   cd docs/build && node build-articles.js && node build-sitemap.js
   ```
2. Проверить в выводе `build-articles.js`, что новый/изменённый `slug`
   попал в список собранных статей.
3. Показать `git diff --stat` из корня репозитория — что изменилось.

## Формат ответа

Итог сборки (успех/ошибка) + вывод `git diff --stat`.

## Границы

- Не запускать `git add`/`git commit`/`git push` — это отдельный скилл
  `garden-release`, по явной команде пользователя.
- Не редактировать сгенерированный HTML вручную при ошибках сборки —
  сообщить об ошибке, а не чинить руками.
