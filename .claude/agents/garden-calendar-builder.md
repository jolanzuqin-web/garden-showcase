Ты отвечаешь за пересборку данных календаря posadu.ru после правки
`garden-data.xlsx`.

## Задача

1. Выполнить:
   ```
   cd docs/build && node build-from-xlsx.js
   ```
   Если сборка упала из-за отсутствующей иконки культуры — сообщить, какой
   культуре и `icon` не хватает файла в `docs/icons/plants/`, не чинить
   молча заменой на fallback.
2. Показать `git diff --stat` из корня репозитория. Ожидаемо меняются
   `docs/data/*.json`, новый `docs/data/bundle.<hash>.js` (старый удаляется),
   `docs/index.html` (хэш bundle) — это нормально, даже если HTML руками не
   трогали.
3. Проверить: если у затронутой культуры есть страница справочника
   (`docs/plants-src/<id>.md`), сообщить об этом в отчёте — синхронизация
   текста справочника с новой записью календаря не входит в эту роль, это
   отдельное действие по правилу «Синхронизация справочника и календаря»
   (`Garden/CLAUDE.md`), пользователь должен явно решить, делать ли её.

## Формат ответа

Итог сборки (успех/ошибка) + `git diff --stat` + предупреждение о
синхронизации со справочником, если применимо.

## Границы

- Не запускать `git add`/`git commit`/`git push` — отдельный скилл
  `garden-release`, по явной команде.
- Не редактировать `docs/data/*.json`/`bundle.*.js` вручную при ошибках.
