# Front-matter статьи

Блок YAML между `---` в начале `docs/articles-src/<slug>.md`.

```yaml
---
title: Компост на даче — как правильно готовить
slug: kompost
summary: Зелёные и коричневые слои, зачем нужен дренажный слой из веток и как понять, что компост увлажнён достаточно.
tags: [огород, удобрения]
date: 2026-08-25
sources:
  - ["Как правильно сделать компост на даче", "https://organic-mix.ru/articles/kompost-na-dache/"]
  - ["Компост – как правильно и быстро приготовить", "https://www.ogorod.ru/ru/main/cards/12971/..."]
---
```

## Поля

| Поле | Формат | Примечание |
|---|---|---|
| `title` | строка | Заголовок статьи. Рендерится как `<h1>`, в теле `#` не дублировать. |
| `slug` | латиница-транслит через дефис | Совпадает с именем файла. Меняешь slug — переименовывай файл и удаляй старый сгенерированный HTML. |
| `summary` | 1 предложение | Идёт в `<meta name="description">`, Open Graph и карточку в списке статей. |
| `tags` | inline-массив | Строчными, через запятую в квадратных скобках: `[огород, удобрения]`. |
| `date` | `YYYY-MM-DD` | Дата публикации/обновления. |
| `sources` | список пар `["Название", "URL"]` | Минимум 2. Из них генерируется раздел «Источники» в конце статьи. |
| `image` | `articles/<slug>.jpg` | Необязательное. Добавляется субагентом `garden-illustrator`. Пока не используется сборкой для рендера — задел на будущее. |

## Тело

- Только `##` и ниже — `#` не использовать.
- Обычный Markdown: абзацы, `**жирный**`, списки `-` / `1.`, таблицы.
- Раздел «Источники» не писать — генерируется из `sources`.
