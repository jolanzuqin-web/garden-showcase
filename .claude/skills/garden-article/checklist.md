# Чек-лист источников (агроданные)

Правило проекта: **перед любой агрономической правкой — сначала веб-поиск
подтверждения, потом текст.** Не полагаться на общие знания модели.

## До написания

- [ ] Сделан веб-поиск по теме статьи (сроки, дозировки, препараты, культуры).
- [ ] Собрано **≥ 2 независимых** источника (не перепечатки одного текста).
- [ ] Приоритет источникам: НИИ и опытные станции, профильные агропорталы,
      производители препаратов (для дозировок), региональные с/х ведомства.
      Ниже приоритет: блоги, маркетплейсы, форумы — только как вторичное
      подтверждение.
- [ ] Для регионов кроме Средней полосы — проверено, что именно отличается
      (сроки/культуры), а не скопирована средняя полоса.

## В тексте

- [ ] Каждое числовое утверждение (срок, температура, дозировка, концентрация)
      подтверждено хотя бы одним источником из `sources`.
- [ ] Расхождения между источниками — либо не включены, либо поданы как
      «по разным данным … », без выдумывания «среднего».
- [ ] Названия препаратов — без рекламных оценок, с указанием действующего
      вещества, где уместно.

## После

- [ ] Все использованные URL внесены в `sources` front-matter.
- [ ] Ничего не утверждается «от себя» сверх источников.
