# Пост для ВКонтакте по статье posadu.ru

Источник — **одна** статья из `docs/articles-src/`. Выход — JSON с текстом
поста и промптом картинки + сгенерированная иллюстрация. Публикация в ВК —
отдельный шаг, не в этом скилле.

## Шаги

1. **Уточнить источник.** Спросить `slug` статьи (файл
   `docs/articles-src/<slug>.md`) или дать выбрать из списка
   `ls docs/articles-src/`.

2. **Прочитать статью целиком.** Взять `title`, `summary` из front-matter и
   текст. Не добавлять факты, цифры, сроки, названия препаратов сверх того,
   что есть в статье — если для поста не хватает конкретики, писать обобщённо,
   а не додумывать.

3. **Собрать JSON поста** по схеме:
   ```json
   {
     "source_slug": "",
     "platform": "vk",
     "text": "",
     "link": "https://posadu.ru/articles/<slug>.html",
     "image_prompt": ""
   }
   ```
   - `text` — 700–1500 знаков. ВКонтакте обрезает длинные посты кнопкой
     «Показать полностью» примерно после 2–3 строк — первая фраза должна
     цеплять и работать самостоятельно, без хвоста. Тон — тёплый, по-соседски,
     без канцелярита и без хайпа (как статьи сайта). Без хэштегов (для ВК
     сообщества по садоводству не приняты, только шумят). Ссылка на статью —
     последней строкой.
   - `image_prompt` — на английском, акварельная иллюстрация в стиле
     справочника растений сайта (см. `TZ_spravochnik-rasteniy-illustracii.md`,
     раздел «Базовый промпт», за образцом формулировок и негатив-листа), сюжет
     по теме статьи, без текста и надписей на картинке.

4. **Сгенерировать иллюстрацию** — вызвать MCP-инструмент `generate_image`
   (сервер `yandexart`) с получившимся `image_prompt`, `size: "1024x1024"`,
   `filename: "<slug>"`. Файл сохранится в `mcp-servers/yandexart/output/`.

5. **Сохранить JSON** в `content-factory/posts/<YYYY-MM-DD>-<slug>.json`.

6. **Показать результат перед публикацией**: текст поста и картинку — чтобы
   можно было поправить формулировки или перегенерировать картинку до того,
   как пост уйдёт в ВК.

## Куда сохраняется результат

- `content-factory/posts/<дата>-<slug>.json` — текст и метаданные поста
  (идёт в git — это лог того, что публиковалось).
- `mcp-servers/yandexart/output/<slug>.jpg` — иллюстрация (не в git,
  регенерируется по промпту из JSON при необходимости).

## Границы

- Не публиковать в ВК из этого скилла — только подготовка контента.
- Не выдумывать факты сверх статьи-источника.
- Один запуск — один пост, не пакетная генерация по всем статьям сразу.
