# Публикация сайта

Деплой сайта = push в ветку деплоя → Timeweb собирает автоматически. Отдельного
шага сборки на хостинге нет.

## Предпроверка

1. `git status` и `git diff --stat` — показать пользователю, что уходит.
2. **Сверка источник ↔ генерат:**
   - изменились `docs/data/*.json` или `docs/data/bundle.*.js`, но не
     `garden-data.xlsx` → скорее всего сборка без правки источника; уточнить.
   - изменились `docs/articles/*.html`, но не `docs/articles-src/*` → то же.
   - если правился `garden-data.xlsx` / `docs/articles-src/*`, но нет
     соответствующих генератов → не запущены `build-from-xlsx.js` /
     `build-articles.js`; сначала пересобрать.
3. **Ветка деплоя.** `git branch --show-current`. По конвенции проекта деплой
   идёт с `master`. Если текущая ветка не `master` — **остановиться и спросить**,
   как публикуем (merge в `master`, или push этой ветки). Не угадывать, не
   делать `reset`/`--force`.

## Коммит

- Сообщение — **на русском**, по сути правок (как в истории репозитория):
  - строка-заголовок ≤ ~72 символов, без точки;
  - тело — что и зачем изменено, конкретика (файлы, значения, причина);
  - для агроправок — пометка «подтверждено веб-поиском».
- Трейлер в конце сообщения:
  ```
  Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>
  ```
- `git add -A && git commit` (без `--no-verify`, без обхода хуков).

## Публикация

- `git push` в ветку деплоя.
- Никаких `push --force`, `reset --hard`, правок чужой истории.

## После push

- Отработает `deploy-smoke-check.yml`: до 8 минут сверяет `Last-Modified`
  `https://posadu.ru/articles/index.html` с временем коммита; если прод не
  догнал — присылает админу в Telegram через `POST /admin-notify` воркера.
  Сообщить пользователю, что проверка идёт.
- Если менялся SEO-контент календаря — снимок в `index.html` / `docs/kalendar/`
  обновит `refresh-calendar-snapshot.yml` отдельным коммитом от бота.

## Границы

- **Только по явной команде** пользователя.
- `worker/**` этот скилл НЕ публикует: изменения бота требуют `wrangler deploy`
  отдельной командой.
- Секреты и `.env` не коммитить.
