# Еженедельная статья без ручного выбора темы

Автоматизирует только выбор темы и запуск пайплайна `garden-article`.
Публикация остаётся под контролем человека — агрономические факты в
садоводстве нельзя выпускать без подтверждения, а тема без финальной
проверки человеком тем более.

## Пайплайн

1. **`garden-topic-scout`** — вход: без параметров (сам определяет сезон и
   читает существующие статьи). Выход: JSON `{ topic, slug, reasoning,
   sources, rejected_candidates }`.
   - Если скаут не смог уверенно выбрать тему (см. его «Границы») —
     остановиться и сообщить пользователю, не придумывать тему самому.
2. Дальше — **весь пайплайн скилла `garden-article`** с темой и `slug` от
   шага 1, начиная с шага 1 того скилла (`garden-researcher`) и до
   `garden-article-builder` включительно. Следовать правилам скилла
   `garden-article` буквально (включая автовозврат на переисследование у
   `garden-agronomist`, лимит в 2 круга, повтор иллюстрации при отклонении
   редактором) — этот скилл не переопределяет их, только добавляет шаг 1
   перед ними.

## После пайплайна

Показать пользователю (в финальном сообщении, это может быть отдельный
запуск по расписанию — пользователь увидит отчёт при следующей проверке):

- Выбранная тема, `slug`, обоснование и источники обсуждаемости от
  `garden-topic-scout` (включая отклонённые кандидаты — почему не они).
- `git diff --stat` и отчёт `garden-editor` — как в `garden-article`.
- Явным текстом: «Черновик готов к проверке. Для публикации — команда
  «коммить и публикуй»».

**Никогда не вызывать `garden-release` из этого скилла** — ни автоматически,
ни по умолчанию, даже если пайплайн прошёл без единого спорного момента.

## Границы

- Тема выбирается автоматически, но публикация — только по явной команде
  человека, как и в `garden-article`.
- Если это запуск по расписанию и что-то в пайплайне остановилось (нет
  уверенной темы, `rejected_tezisy` не закрылись за 2 круга, спор по
  иллюстрации не решился) — не пытаться продавить результат, зафиксировать
  проблему в отчёте и закончить на этом шаге.
