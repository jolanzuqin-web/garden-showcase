# PRD — промо-лендинг Telegram-бота «Календарь садовода»

> Техдокумент к домашней работе CLs02 (вариант 2). Составлен до генерации
> страницы. Вне сборки сайта — справочный файл рядом с `index.html`.

## 1. Цель

Одна страница с воронкой Hero → Польза → Доверие → CTA → Футер, которая
конвертирует посетителя в подписчика бота `@garden_calendar_notify_bot`.
Сейчас подписка живёт одной строкой внутри календаря (`docs/index.html`,
блок `.subscribe-block`) — отдельной посадочной у бота нет.

## 2. Целевая аудитория

Дачники и садоводы РФ, преимущественно 40+. Боль: в начале каждого месяца
не помнят, какие работы уже пора делать в своём регионе, и узнают о сроках
задним числом (не подвязали, не обработали, не укрыли вовремя).

## 3. Структура секций

| Секция | Задача | Содержание |
|---|---|---|
| **Hero** | Зацепить за боль + первичный CTA | Гусь-смотритель (акварельная иллюстрация `img/bot-hero.webp` — гусь у настенного календаря), H1 про напоминание 1-го числа, кнопка «Открыть в Telegram» |
| **Польза** | Объяснить ценность | 3 карточки: (1) рассылка 1-го числа по твоему региону; (2) работы разбиты по декадам и типам (посев, обрезка, подкормка, обработка…); (3) агротехника со ссылками на проверенные источники |
| **Доверие** | Снять сомнения | Данные сверяются по открытым источникам перед публикацией; 4 региона РФ (Средняя полоса, Юг, Урал и Сибирь, Северо-Запад); ссылки на статьи `/articles/`; пример сообщения бота |
| **CTA** | Действие | Выбор региона (`<select>`) + кнопка → `t.me/garden_calendar_notify_bot?start=<region>`; вторичная ссылка «Открыть календарь на сайте» |
| **Футер** | Служебное | Ссылка на `posadu.ru`, «материалы по открытым источникам», тумблер темы в шапке |

## 4. Технический стек

- Vanilla HTML + один инлайн `<style>` (правила только для лендинга).
- Общий слой оформления переиспользуется из `../css/style.css` (токены,
  шрифты, тёмная тема, `.page-sheet`, `.topbar`, `.footer`, `.card`,
  `.goose-*`, `.btn-secondary`).
- Один инлайн `<script>` (~15 строк): выбор региона для ссылки + тумблер
  темы (копия логики со страниц статей).
- Без фреймворков, без сборки, без внешних CDN.

## 5. Файловая структура

```
docs/bot/
├── PRD.md        ← этот файл
└── index.html    ← лендинг
```
Ассеты: `../css/`, `../fonts/`, `../favicon.svg`, `../og-image.png` — общие с
сайтом; `../img/bot-hero.webp` — иллюстрация лендинга (акварельный гусь у
календаря), 900×900, ~150 КБ.

## 6. Дизайн

Концепт «Дневник садовода» (storybook-акварель), уже принятый для сайта:
лист бумаги с нарисованной рамкой (`.page-sheet` + `.page-frame`), рукописные
акценты, приглушённая палитра из токенов `--primary/--accent/--bg`, тёмная
тема через `data-theme`. Сезонная палитра (`[data-season]`) — как на сайте.

## 7. Тексты-заглушки

- **H1:** «Что делать в саду в этом месяце — напомним 1-го числа»
- **Подзаголовок:** «Телеграм-бот присылает список сезонных работ по вашему
  региону: посев, обрезка, подкормка, защита от вредителей — в срок, а не
  задним числом.»
- **Кнопка Hero:** «Открыть в Telegram»
- **Польза 1:** «Раз в месяц, 1-го числа — что делать в саду и огороде
  именно сейчас, с учётом вашего региона.»
- **Польза 2:** «Работы разбиты по декадам месяца и типам: не сплошной
  список, а понятно, что раньше, что позже.»
- **Польза 3:** «Каждая рекомендация — со сроками, препаратами и ссылками на
  источники. Спорные данные сверяем перед публикацией.»
- **Доверие:** «4 региона РФ. Данные собраны по открытым агрономическим
  источникам — ссылки указаны в статьях.»
- **CTA:** «Выберите регион и подпишитесь — бот пришлёт первую сводку сразу.»

## 8. Проверка (итерации)

1. `node docs/server.js` → `http://localhost:8177/bot/index.html`.
2. Скриншот десктоп + мобильный (эмуляция 375px).
3. Минимум одна правка по скриншоту.

## 9. Вне рамок этой итерации

Деплой на `posadu.ru/bot/`, запись в `sitemap.xml`, реальный скриншот бота,
A/B заголовков.
