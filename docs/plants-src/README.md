# Справочник растений — формат источников

Каждый файл `<id>.md` — одна культура. `<id>` совпадает с `id` культуры в листе
`Plants` (`plants.json`). Сборка: `node docs/build/build-plants.js` из
`docs/build`. HTML в `docs/plants/` и `docs/data/plant-pages.json` —
**сгенерированы**, руками не трогать.

**Картинки культур:** `docs/img/plants/<id>.webp` (≈700px) — для страниц
культур. Для сетки на `plants/index.html` нужны миниатюры
`docs/img/plants/thumb/<id>.webp` (220px): после добавления или замены любой
картинки запустить `node docs/build/make-plant-thumbs.js` (перегенерит только
изменённые), затем `build-plants.js`.

Перед любой агрономической правкой — веб-поиск подтверждения (правило проекта),
ссылки — в `sources` front-matter. Синхронизация с календарём
(`garden-data.xlsx` → лист `Calendar`) — по разделу «Синхронизация справочника и
календаря» в [../../CLAUDE.md](../../CLAUDE.md).

## Front-matter (паспорт культуры)

```yaml
plant: tomat                 # = id в plants.json; = имя файла
title: Томат
latin: Solanum lycopersicum
family: Паслёновые
lifeform: однолетник в культуре, травянистое
lifespan: один сезон
propagation: [рассада, прямой посев]
light: полное солнце
soil: "рыхлая; pH 6,0–6,8"
frost: "заморозков не переносит; …"
hardiness: "открытый грунт — средняя полоса и южнее; …"
spacing: "низкорослые 35–40 × 45–50 см; …"
time_to_harvest: "90–130 дней от всходов"
rotation_good: [огурец, лук, бобовые]
rotation_bad: [картофель, перец, баклажан]
companions: [базилик, бархатцы]
difficulty: средняя
summary: "…"                 # meta description и подпись в индексе
tags: [огород, паслёновые, рассада]
date: 2026-09-02
related:                     # [метка, url] — статьи и др.
  - ["Мульчирование грядок и приствольных кругов", "../articles/mulchirovanie.html"]
regions_notes:               # особенности по 4 регионам сайта
  srednyaya-polosa: "…"
  yug: "…"
  ural-sibir: "…"
  severo-zapad: "…"
sources:
  - ["метка", "https://…"]
```

Поля паспорта, которых нет, просто не выводятся. Числовые параметры (pH, схема
посадки, возраст рассады, сроки) должны совпадать с формулировками в столбце
`detail` листа `Calendar` по этой же культуре.

**YAML-нюанс:** если в значении есть двоеточие с пробелом (`… за 3 недели: …`),
всю строку берут в кавычки — `summary: "…"` — иначе сборка падает на разборе
front-matter.

## Размеры кроны по возрасту (`crown_by_age`)

Необязательное поле паспорта — только для древесных и крупнокустарниковых
культур, где крона нарастает годами (плодовые деревья, хвойные, декоративные и
ягодные кустарники). Не добавлять однолетникам, овощам, зелени, травянистым
многолетникам, лианам и почвопокровникам — годовая таблица для них не имеет
смысла. Критерии и полный список культур —
[../../reports/2026-09-05_razmery-krony-po-vozrastu.md](../../reports/2026-09-05_razmery-krony-po-vozrastu.md).

Порядок сбора данных (веб-поиск обязателен на каждом шаге):

1. **Сначала — размер в год посадки/укоренения.** Для черенкуемых культур: длина
   черенка и срок/размер выхода из питомничьей школки. Для семенных или обычно
   покупных саженцев — типовой размер на выходе из питомника.
2. **Затем — подтверждённые сведения по конкретным годам**, какие удастся найти
   (обычно разрозненно: «к N годам», «взрослое растение», сортовые описания).
   Каждая такая точка — со ссылкой в `sources`.
3. **Для промежутков без данных — линейная интерполяция** среднегодового
   прироста между двумя ближайшими подтверждёнными точками. За пределы
   подтверждённого диапазона (моложе первой точки, старше последней) не
   экстраполировать.
4. **`note` пишем для читателя сайта, не для себя** — коротко и по-садовому, без
   слов «источник», «интерполяция», «подтверждено»: для какого сорта/формы
   таблица, как соотнести с купленным саженцем, где рост медленнее/быстрее
   обычного, и оговорка про разброс от ухода и региона. Какие строки откуда
   взяты — держим в голове по правилу выше и в `sources`, в текст на странице
   это не выносим.

Формат:

```yaml
crown_by_age:
  note: "Для какого сорта/формы данные; как соотнести с купленным саженцем;
    где рост медленнее обычного (например, первые годы после черенкования);
    оговорка про разброс от ухода, освещения и региона — коротко, по-садовому."
  rows:
    - ["1 год (черенок укореняется)", "10–15 см", "5–8 см"]
    - ["10 лет", "2–3 м", "≈60 см"]
    - ["20 лет", "5–6 м", "≈120 см"]
```

Пример на живой странице — `tuya.md` / `docs/plants/tuya.html`.

## Тело: этапы жизненного цикла

Вводный абзац (до первого `##`) + разделы `## Заголовок`. Каждый `##` становится
карточкой-этапом; по заголовку подбирается иконка типа работ. «Частые ошибки»
рендерятся отдельным блоком внизу.

Порядок — по жизненному циклу: выбор материала → посадка → (рассада) → высадка →
уход в сезон → защита → уборка → зимовка → завершение/удаление → размножение.

### Обязательные пункты — если для культуры применимо, раздел расписываем, не упоминаем вскользь

- **Посев / посадка** — сроки (привязка к региону), глубина, схема.
- **Полив** — режим, норма, способ, критические фазы.
- **Подкормки** — график по фазам, конкретные удобрения и дозы.
- **Мульчирование** — **чем** (материалы), **какой слой**, **когда**, отступ от
  стебля/ствола. Отдельный раздел или в паре с поливом («Полив и
  мульчирование»), но всегда с конкретикой по материалам, а не одним словом
  «замульчировать».
- **Формировка / обрезка** — пасынкование, подвязка, тип кроны, нормирование.
- **Защита** — 3–6 главных болезней и вредителей именно этой культуры: симптом →
  мера.
- **Уборка урожая** — признаки зрелости, сроки, хранение.
- **Зимовка** (многолетние) — обрезка на зиму, окучивание, укрытие (материал,
  сроки), пригибание.
- **Завершение цикла / удаление** — сроки уборки, судьба растительных остатков
  (компост / вынос и сжигание при болезни), севооборот, что нельзя сажать
  следом.
- **Размножение** — применимые способы.

### Врезки (выделенные блоки)

Во вводном абзаце или внутри раздела:

```
:::remontant
Текст врезки (markdown). Заголовок блока — «Ремонтантные сорта».
:::

:::note Патиссоны и цуккини
Текст врезки (markdown). Заголовок блока — произвольный,
берётся из первой строки после `:::note`.
:::
```

Оба рендерятся как визуально выделенный блок `.agro-note`. Внутри —
обычный markdown (абзацы, списки, **жирный**).
